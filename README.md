# Lesson 5 - AWS Infrastructure with Terraform

Цей проєкт розгортає базову інфраструктуру на AWS за допомогою Terraform з використанням модульної структури.

## Опис структури проєкту
Проєкт складається з трьох основних модулів:

1. **s3-backend**: Налаштовує S3 бакет із версіюванням для зберігання стейт-файлів Terraform та таблицю DynamoDB для блокування одночасного виконання (state locking).
2. **vpc**: Створює мережеву інфраструктуру — VPC, 3 публічні підмережі, 3 приватні підмережі, Internet Gateway для доступу ззовні, NAT Gateway для доступу приватних підмереж в інтернет та відповідні таблиці маршрутизації (Route Tables).
3. **ecr**: Створює репозиторій Elastic Container Registry (ECR) для зберігання Docker-образів з увімкненим скануванням під час push'у та налаштованою базовою політикою доступу.
