# CI/CD Pipeline: AWS EKS, Jenkins, Kaniko & Argo CD

Цей репозиторій містить інфраструктурний код (Terraform) та конфігурації для розгортання повноцінного CI/CD пайплайну в кластері AWS EKS.

Пайплайн автоматично збирає Docker-образ застосунку за допомогою Kaniko (без використання Docker-демона), публікує його в Amazon ECR, оновлює Helm-чарт у Git-репозиторії та автоматично синхронізує зміни в кластері за допомогою Argo CD.

---

## 🚀 Як застосувати Terraform

Вся інфраструктура (VPC, EKS кластер, ECR репозиторій) та базові сервіси (Jenkins, Argo CD) розгортаються автоматично за допомогою Terraform.

**Кроки для запуску:**
1. Переконайтеся, що у вас налаштовані credentials для AWS (`aws configure`).
2. Перейдіть у кореневу папку проєкту, де знаходиться файл `main.tf`.
3. Ініціалізуйте Terraform для завантаження необхідних провайдерів та модулів:
   ```bash
   terraform init
